# 🎵 Pulse - Web Music Player

A modern, responsive web-based music player built with **HTML**, **CSS**, and **JavaScript**. Pulse offers a sleek user interface inspired by popular music streaming platforms with smooth animations and intuitive controls.

## ✨ Features

- 🎶 **Music Playback**: Play, pause, skip, and navigate through your music collection
- 📋 **Song Library**: Browse and manage your local song collection with an easy-to-use playlist system
- 🎨 **Modern UI**: Minimalist dark-themed interface with gradient accents and smooth animations
- 📱 **Responsive Design**: Works seamlessly on desktop and mobile devices
- 🔊 **Volume Control**: Adjust playback volume with an interactive volume slider
- ⏱️ **Playback Progress**: Visual seek bar to track and control song progress
- 🔍 **Search Functionality**: Find songs in your library quickly
- 📱 **Sidebar Navigation**: Home, Search, and Library sections for easy navigation
- 🎯 **Song Information Display**: Real-time display of current song details

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Styling**: Custom CSS with utility classes for responsive design
- **Icons**: SVG-based custom icons for a crisp, scalable UI

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- No installation or dependencies required!

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ayonshukla/Pulse-Music-Player.git
   cd Pulse-Music-Player
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your web browser
   # Or use a local server (recommended for better performance)
   python -m http.server 8000
   # Then navigate to http://localhost:8000
   ```

## 🎮 Usage

### Controls
- **Play/Pause**: Click the play button to start or pause playback
- **Next/Previous**: Use the navigation arrows to skip to the next or previous song
- **Seek Bar**: Click or drag on the progress bar to jump to a specific point in the song
- **Volume**: Use the volume slider to adjust playback volume
- **Browse Library**: Click on any song in "Your Library" sidebar to play it
- **Sign Up/Log In**: Access user authentication features (authentication functionality can be expanded)

### Adding Songs
1. Place your audio files (.mp3, .wav, etc.) in the `songs/` directory
2. The player will dynamically load and display available songs

## 🎨 UI Components

- **Left Sidebar**: Navigation and library management
- **Main Content Area**: Song discovery and playlist display
- **Player Bar**: Playback controls and progress tracking
- **Controls**: Previous, Play/Pause, Next buttons
- **Seekbar**: Visual progress indicator with drag-to-seek functionality
- **Volume Control**: Volume slider for audio level adjustment

## 🔧 Customization

### Styling
- Modify `css/style.css` for main styling
- Update `css/utility.css` for utility classes and responsive breakpoints
- Color scheme uses purple (#ff00cc to #333399) gradient accent

### JavaScript Functionality
- Edit `js/script.js` to customize player behavior
- Extend features like shuffle, repeat, or playlist management
- Add API integrations for online music sources
